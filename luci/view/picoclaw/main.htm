📝 AI 模型配置指南

📋 切换模型（两步）
1. 在 config.json → model_list 中加条目：model_name / provider / model / api_base（密钥不放这里，见下方说明）
2. 把 agents.defaults.model_name 指向条目的 model_name，可一条命令搞定：picoclaw model <名字>，然后重启服务
0.3.1 起配置是严格校验的：model_list 条目只认 model_name / provider / model / api_base / api_keys / enabled，写进 max_tokens、context_window、temperature 这类字段会让 PicoClaw 直接拒绝加载整个 config.json（服务起不来）。
